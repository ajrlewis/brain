# Alembic Preset

Adopted for all Brain schema changes once persistence exists. Every schema change must include a reviewed migration and relevant PostgreSQL integration coverage.

- Generate new migrations for new schema changes; do not edit migrations that may already be applied.
- Inspect autogenerated migrations before committing them.
- Make upgrade steps safe for the target data volume and deployment model.
- Provide meaningful downgrade behavior when the project requires downgrades.
- Test migration paths where practical.
- Keep model metadata and migration state aligned.
